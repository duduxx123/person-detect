# 基于 YOLO11 与 ReID 的增强型行人跟踪系统

本项目在 **YOLO11** 的基础上实现了一套先进的行人跟踪系统。通过在标准 BoT-SORT 跟踪器之上构建一个复杂的 **Re-Identification (ReID, 行人重识别)** 身份管理系统，显著提升了跟踪的连续性。

## 🚀 核心动机

传统的跟踪器在目标被遮挡或暂时离开画面后，经常会出现 **ID 切换 (ID Switching)** 的问题。虽然 BoT-SORT 在短时关联方面表现出色，但缺乏长时记忆能力。

本实现通过引入 **多级身份恢复机制** 解决了这一问题。系统能够根据人物的外观特征（Embedding）来“记住”并“认回”个体，即使底层跟踪器已经为其分配了新的 `track_id`，系统依然能将其映射回原有的全局 UUID。

---

## 🏗️ 系统架构

为了确保最大限度的身份连续性，系统采用了三层关联策略：

### 第一层：短时关联 (YOLO + BoT-SORT)
- **职责**：逐帧检测与基础跟踪。
- **机制**：调用标准 `yolo.track()` 配合 BoT-SORT 处理即时关联。
- **输出**：产生临时的 `track_id`。

### 第二层：中时恢复 (Lost Tracks)
- **职责**：恢复短至中期消失后的身份。
- **机制**：当 `track_id` 消失时，其状态被移入 `lost_tracks` 缓冲区。当新 `track_id` 出现时，系统结合 **外观相似度 + 空间接近度 + 时间衰减** 在此缓冲区中检索匹配项。

### 第三层：长时记忆 (Identity Bank)
- **职责**：处理“远场重入”场景（例如：行人从屏幕左侧离开，随后从右侧返回）。
- **机制**：`identity_bank` 存储高质量的特征向量，有效期较长（默认 90 秒）。此层匹配主要依赖极高相似度的 ReID 特征，因为此时空间接近度已失去参考价值。

## 🛠️ 技术亮点

### 1. 特征质量控制
为了防止模糊或被遮挡的“坏特征”污染特征库，系统实现了严格的质量过滤：
- **质量评分**：综合 **检测置信度、边界框尺寸、长宽比、图像锐度（Laplacian 方差）** 计算综合质量分。
- **特征平滑**：采用指数平滑法 $\text{blend} = \alpha \cdot \text{prev} + (1-\alpha) \cdot \text{curr}$，减少单帧特征波动带来的噪声。
- **身份画廊 (Identity Gallery)**：每个 UUID 不仅存储单一向量，而是维护一个 **Gallery**（最多 6 个不同姿态的特征），以捕捉人物在不同角度和姿态下的外观。

### 2. 动态空间约束
空间搜索窗口并非固定，`adaptive_center_distance_limit` 会根据以下因素动态调整：
- **目标尺寸**：目标越大，允许的中心点偏移量略微增加。
- **丢失时长**：目标消失时间越久，搜索范围相应扩大。
- **估计速度**：根据最后一次已知速度预测目标可能移动的位置。

### 3. 加权重识别评分机制
在将新检测目标与候选身份匹配时，采用多因子综合评分：

$$ \text{Score} = 0.7 \cdot \text{max\_sim} + 0.1 \cdot \text{mean\_sim} + 0.08 \cdot \text{IoU} + 0.08 \cdot \text{spatial\_score} + 0.08 \cdot \text{quality} - 0.04 \cdot \text{time\_penalty} $$

**关键项说明：**
- **$\text{max\_sim}$**：当前特征与身份画廊中最高相似度。
- **$\text{mean\_sim}$**：平均相似度，用于增强稳定性。
- **Spatial Score**：与最后已知位置的接近程度。
- **候选边际 (Candidate Margin)**：为了避免歧义匹配，计算第一名和第二名候选者的相似度之差；若差距过小，则判定为匹配模糊并拒绝认回。

## 🔄 执行工作流

1. **检测**：YOLO11 在当前帧中检测所有行人。
2. **短时跟踪**：BoT-SORT 分配 `track_id`。
3. **特征提取**：ReID 编码器生成视觉特征向量。
4. **身份映射**：
   - 若 `track_id` 已知 $\rightarrow$ 更新当前状态。
   - 若 `track_id` 为新 $\rightarrow$ 检索 `lost_tracks` $\rightarrow$ 检索 `identity_bank`。
   - 匹配成功？ $\rightarrow$ 继承原有的 **UUID**。
   - 匹配失败？ $\rightarrow$ 创建全新的 **UUID**。
5. **更新画廊**：若图像质量达标，将该特征加入 UUID 的画廊中。
6. **状态管理**：将消失的轨迹移入 `lost_tracks` 并同步更新 `identity_bank`。

## ⚙️ 核心调优参数

| 参数 | 说明 | 建议范围 |
| :--- | :--- | :--- |
| `REID_SIMILARITY_THRESHOLD` | 认回身份的基础相似度阈值 | $0.70 - 0.80$ |
| `LOST_UUID_TTL_SECONDS` | 中时缓冲区保留时间 | $10 - 30s$ |
| `IDENTITY_BANK_TTL_SECONDS` | 长时记忆保留时间 | $60 - 300s$ |
| `REID_EMBEDDING_BLEND` | 特征平滑系数 | $0.80 - 0.95$ |
| `MIN_REID_QUALITY_SCORE` | 更新特征画廊的最低质量分 | $0.40 - 0.60$ |
